นโยบายความเป็นส่วนตัว DocDee PDF

ปรับปรุงล่าสุด: 16 พฤศจิกายน 2569

DocDee PDF

  • DocDee PDF ทำงานในเครื่องของคุณ เอกสาร ข้อความที่สแกน (OCR) และลายเซ็นของคุณไม่ถูกส่งออกจากเครื่อง
  • โปรแกรมไม่เก็บสถิติการใช้งานและไม่ติดตามผู้ใช้
  • ข้อความจาก Supakor.Studio หรือผู้สนับสนุนที่แสดงในหน้าแรกของโปรแกรม ติดมากับตัวโปรแกรม ไม่โหลดจากอินเทอร์เน็ต และไม่เก็บข้อมูลว่าใครเห็นหรือกด เมื่อคุณกดลิงก์ เบราว์เซอร์จะเปิดเว็บไซต์นั้น ซึ่งมีนโยบายของตัวเอง
  • หากในอนาคตมีฟีเจอร์ที่ต้องใช้อินเทอร์เน็ต (เช่น ตรวจหาอัปเดต หรือผู้ช่วย AI) เราจะแจ้งในนโยบายนี้ และให้คุณเลือกเปิดหรือปิดเองก่อนส่งข้อมูลใดๆ

เว็บไซต์นี้

  • เว็บไซต์นี้ไม่มีคุกกี้ ไม่มีระบบสมาชิก และไม่มีโค้ดติดตาม (analytics) ของเรา
  • เว็บไซต์ให้บริการโดย GitHub Pages และโหลดไลบรารีภาพ 3D (Three.js) จาก jsDelivr ทั้งสองผู้ให้บริการอาจบันทึกข้อมูลการเข้าถึงทางเทคนิค เช่น ที่อยู่ IP ตามนโยบายของตน
  • ลิงก์ไปยัง YouTube และเว็บไซต์อื่น เป็นไปตามนโยบายความเป็นส่วนตัวของเว็บไซต์นั้นๆ
