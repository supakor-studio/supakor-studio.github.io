DocDee PDF

โปรแกรมจัดการ PDF ฟรี หน้าจอภาษาไทยทั้งหมด ทำมาเพื่องานเอกสารของคนไทยโดยเฉพาะ

  • อ่าน รวม แยก หมุน จัดหน้า PDF
  • แก้ไขข้อความ เพิ่มข้อความ รูปภาพ ลายเซ็น
  • สแกนเป็นข้อความ (OCR) ภาษาไทย อ่านเลขไทย ๐–๙ ได้
  • ฟอนต์ Sarabun แบบหนังสือราชการ
  • วันที่แบบ พ.ศ. และเลขไทย
  • กรอกฟอร์ม ใส่หัวกระดาษ ลายน้ำ
  • ทำงานในเครื่อง ไม่ส่งไฟล์ของคุณขึ้นอินเทอร์เน็ต
  • รองรับหลายภาษา รวมถึงภาษาอาเซียน
⬇ รับจาก Microsoft Store ตัวติดตั้ง .msi รุ่นทั้งหมด / แบบไม่ต้องติดตั้ง

รุ่น 0.21.1 · Windows 10/11 (64 บิต) · ฟรี
แนะนำให้ติดตั้งจาก Microsoft Store: ติดตั้งง่าย ไม่มีคำเตือน และอัปเดตให้อัตโนมัติ
ถ้าใช้ตัวติดตั้ง .msi แล้ว Windows ขึ้นหน้าจอ "Windows protected your PC" ให้กด More info แล้วกด Run anyway ที่ขึ้นแบบนี้เพราะตัวติดตั้งยังไม่ได้ลงลายเซ็นดิจิทัล ไม่ได้แปลว่าไฟล์มีไวรัส ตรวจไฟล์ได้ด้วยค่า SHA-256 ในหน้ารุ่นนั้น
